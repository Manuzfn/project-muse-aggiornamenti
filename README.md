# Aggiornamenti di Visualize Your Emotions

Questo repository contiene solo gli installatori di Visualize Your Emotions per Windows, niente codice. L'app
installata legge `latest.json` all'avvio e, se c'è una versione nuova, propone di aggiornarsi da sola.

Fino alla versione 0.10.x l'app si chiamava Project Muse: per questo il repository ha ancora quel nome, che è
scritto nelle app già installate. Le app con il vecchio nome si aggiornano come sempre e prendono il nome nuovo.

Ultima versione: **0.14.0** (2026-11-24) — [VisualizeYourEmotions-Setup-0.14.0.exe](https://raw.githubusercontent.com/Manuzfn/project-muse-aggiornamenti/main/VisualizeYourEmotions-Setup-0.14.0.exe)
